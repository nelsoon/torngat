# Security policy

Torngat is pre-alpha and not ready for production use.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/nelsoon/torngat/security/advisories/new).
Do not open a public issue.

Include the affected version or commit, a description of the impact and steps to reproduce. You
will get an acknowledgement within a few days.
